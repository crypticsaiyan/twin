[apache/echarts#21538](https://github.com/apache/echarts/issues/21538) (open when this was recorded) reports that `roundTime_locale` in `test/ut/spec/util/time.test.ts` fails in any time zone with daylight saving time. A maintainer in a zone without DST runs the same test and it passes. That is the "works on my machine" situation twin is built for.

Every file referenced here is in [`examples/echarts-21538`](https://github.com/crypticsaiyan/twin/tree/main/examples/echarts-21538). All runs were recorded on Solari on 2026-09-28.

| File | What it is |

| `kolkata.json` | capsule from a maintainer in `Asia/Kolkata`: the test passes |
| `replay.txt` | `twin replay new-york.json` |
| `bisect.txt` | `twin bisect new-york.json --good kolkata.json` |

## 4. The cause

The test builds its expected dates with a fixed UTC offset taken from January 1970:

```ts
// return timezone format like `'-06:00'` or `'+05:45'`
function getISOTimezone(): string {
    const offsetMinutes = (new Date(0)).getTimezoneOffset();
    ...
}
```

That offset is wrong for October in any zone with daylight saving time, so the expected value is off by exactly one hour (`528526800000 - 528523200000 = 3600000` ms). `roundTime(..., false)` itself works in local time and is correct.

## 5. Verify: 71 s

`fix.patch` drops the offset: an ISO date-time string without one is parsed as local time, which is what `roundTime(..., false)` works in.

```diff title="fix.patch (excerpt)"
         it('roundTime_locale', function () {
-            const timezoneStr = getISOTimezone();
-            const time1 = new Date(`1986-10-06T11:25:45.678${timezoneStr}`);
+            // A date-time string without an offset is local time, which is what roundTime
+            // uses when isUTC is false. A fixed offset would ignore daylight saving time.
+            const time1 = new Date('1986-10-06T11:25:45.678');
 
             expect(roundTime(new Date(time1), 'year', false).getTime())
-                .toEqual(new Date(`1986-01-01T00:00:00.000${timezoneStr}`).getTime());
+                .toEqual(new Date('1986-01-01T00:00:00.000').getTime());
```

The patch passes locally under seven zones (New York, Berlin, Sydney, Kolkata, UTC, Chatham, São Paulo). `twin verify` then rebuilt the New York reporter's environment on a fresh sandbox, applied the patch on top of the captured commit and ran the test. Nothing had to be pushed first.

   ```sh
   export SOLARI_API_KEY=slr_live_...
   twin replay examples/echarts-21538/new-york.json
   twin bisect examples/echarts-21538/new-york.json --good examples/echarts-21538/kolkata.json
   twin verify examples/echarts-21538/new-york.json --patch examples/echarts-21538/fix.patch
   ```

2. Without a key, against a local Docker container (development harness, same guest scripts):

   ```sh
   pnpm e2e:docker examples/echarts-21538/new-york.json
   ```
